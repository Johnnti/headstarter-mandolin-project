### How to Run

1.  **Install Dependencies**

    Open a terminal and run the following command to install the required Python packages from the `pipeline` directory:

    ```bash
    pip install -r pipeline/requirements.txt
    ```

2.  **Run the Notebook**

    Navigate to the `pipeline` directory and run the Jupyter Notebook:

    ```bash
    cd pipeline
    jupyter notebook demo.ipynb
    ```
